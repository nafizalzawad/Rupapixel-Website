## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/nafizalzawad/Rupapixel-Website.git

# Enter project directory
cd Rupapixel-Website

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
```
The optimized static build output will be generated inside the `dist/` directory, ready for deployment to Vercel, Netlify, or GitHub Pages.
